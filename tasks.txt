1. Класс Candidate. Поля String name, String photo, int transient voteCount (по умолчанию 0), и идентификатор String Id.
Без конструктора, но с геттерами для freemarker.

2. Класс Session. Сессия. Нужна для того, чтобы отслеживать сессию пользователя через куки. Логика такая, что под одним
куки будет храниться список из всех dataModel которые нам будут нужны.

3. Дата модели. Класс DataModel с логикой: 1) dataModel с логикой для страницы "/" (candidates.html). Тут
парсинг candidates.json и работа с данными объекта Candidate 2) dataModel с логикой для страницы "/votes"
(votes.html). Передаем такой же map что и в dataModel #1, но еще дополнительно передадим соотношение голосов к
кандидатам. 3) dataModel с логикой для страницы "/thankyou" (thankyou.html). Здесь нужен парсинг либо query (GET)
либо body (POST), и обновляем поле voteCount через сеттер. Тут берем предыдущую модель #1 и фильтром оставляем только
одного кандидата, чтобы получить соответствующий мап.

4. Обновить шаблоны freemaker в соответствии с соответствующими dataModel.
